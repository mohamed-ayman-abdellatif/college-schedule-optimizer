# 🏛️ College Schedule Optimizer — Schedules & Subjects Branch (`schedules-data`)

This branch hosts the university schedule catalogs, unified searchable subject index, individual per-subject JSON files, and full faculty schedule datasets for the **[College Schedule Optimizer](https://github.com/mohamed-ayman-abdellatif/college-schedule-optimizer)**.

## 📁 Branch Structure

```
├── index.json                                  # Master faculty catalog manifest
├── subjects_index.json                         # Lightweight global subject search index (593 subjects)
├── subjects/
│   ├── computing_heliopolis_2026_term1/        # Individual KB-sized subject JSONs for instant retrieval
│   └── engineering_heliopolis_2026_term1/
└── colleges/
    ├── computing_heliopolis_2026_term1.json    # Complete faculty schedule dataset
    └── engineering_heliopolis_2026_term1.json
```
